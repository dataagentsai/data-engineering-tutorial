# Data Engineering Tutorial

Hand-drawn, question-first lessons on how data platforms work, from the till to the dashboard, with one tab per
cloud. Source for [cleandataengineering.ai/learn/](https://cleandataengineering.ai/learn/), where the simulators
(DataTwin Studio, Delta and Spark internals, the Problem Lab) are already live.

Status: not started as a repository. Lessons are added here as each piece of the data platform is built.
